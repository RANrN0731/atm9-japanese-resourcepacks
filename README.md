# ATM9 No Frills 日本語リソースパック

Minecraft Java Edition **1.20.1 / All the Mods 9 - No Frills** 向けの日本語化パックです。

## ダウンロード

下のリンクからZIPを保存してください。ZIPは解凍しません。

- [ATM9のMOD・説明書の日本語パック](https://github.com/RANrN0731/atm9-japanese-resourcepacks/releases/latest/download/All.the.Mods.9.-.No.Frills-JP_EX.zip)
- [PNCRマニュアル本文の日本語補完パック](https://github.com/RANrN0731/atm9-japanese-resourcepacks/releases/latest/download/PNCR-Manual-Japanese-1.20.1.zip)

## 入れ方

1. CurseForgeで **All the Mods 9 - No Frills** のフォルダを開きます。
2. `resourcepacks` フォルダに上のZIPを2つとも入れます。
3. ゲームの「設定 → リソースパック」で両方を有効にします。
4. 選択中のパックの順番を、上から次のようにします。

   - **PNCR-Manual-Japanese-1.20.1.zip**
   - **All.the.Mods.9.-.No.Frills-JP_EX.zip**

5. ゲームの言語を「日本語」にします。起動中に追加・更新した場合は、F3 + Tでリソースを再読み込みします。

各プレイヤーのクライアントに入れて使用します。

## 内容と注意点

- ATM9のパックはYakuCraftで書き出した日本語訳です。機械翻訳による誤訳や未翻訳が残る場合があります。
- PNCR補完パックは **PneumaticCraft: Repressurized 6.0.20 / Minecraft 1.20.1** のマニュアル向けです。説明書の235個のJSONファイルを収録しています。
- PNCR補完パックでは、元のレシピID、アイテムID、ページ構成を保ち、表示文章を日本語化しています。API関数名・MOD名などの固有名詞は原表記を残しています。
- クエストの達成条件やサーバーの進捗を修復するパックではありません。
- Minecraft本体、MODのJAR、ワールド、サーバー設定は含みません。
